# 快速开始

## 一、引用

`Runtime/Fang.Framework.asmdef` 的 `autoReferenced` 为 `true`，`Assets/` 下的预定义程序集（`Assembly-CSharp`）可直接使用：

```csharp
using Fang.Framework;
```

如果代码位于自定义 asmdef 中，需要在 asmdef 的 `references` 里加上 `Fang.Framework`。

## 二、定义领域

```csharp
using Fang.Framework;
using UnityEngine;

public sealed class ItemConfigDataSo : ConfigDataSo
{
    [SerializeField] private int _maxStack;
    [SerializeField] private int _baseDamage;

    public int MaxStack => _maxStack;
    public int BaseDamage => _baseDamage;
}

public sealed class ItemData : Data<ItemConfigDataSo>
{
    private int _count;
    private int _durability;

    public ItemData(ItemConfigDataSo config) : base(config)
    {
        _count = 1;
        _durability = config.BaseDamage;
    }

    public int Count => _count;
    public int Durability => _durability;

    public void Add(int amount)
    {
        _count = Mathf.Clamp(_count + amount, 0, Config.MaxStack);
    }

    public void ApplyDamage(int amount)
    {
        _durability = Mathf.Max(0, _durability - amount);
    }
}

public sealed class ItemController : Controller<ItemConfigDataSo, ItemData>
{
}

public sealed class ItemWorldObject : WorldObject<ItemController, ItemData, ItemConfigDataSo>
{
}
```

要点：

- 配置字段是 `private [SerializeField]`，对外只有只读属性。写配置走 `SerializedObject` / `SerializedProperty` + `EditorUtility.SetDirty`。
- `Data` 只有带参构造，`Config` 在构造时就位。
- `Data` 自己的状态由自己的方法改（`Add` / `ApplyDamage`），不变量在方法里守。

## 三、定义能力

```csharp
using Fang.Framework;

public interface IInventory
{
    void Add(ItemData item);
}

public sealed class InventoryService : Service, IInventory, IInitializable
{
    private readonly List<ItemData> _items = new List<ItemData>();

    public void Initialize()
    {
    }

    public void Add(ItemData item)
    {
        _items.Add(item);
    }
}
```

`Service` 本身没有任何成员，它是「由 Scope 创建、装配与释放的长期能力」的语义标记。需要初始化能力的子类自行实现 `IInitializable`。

## 四、装配

```csharp
using Fang.Framework;
using UnityEngine;

public sealed class GameBootstrap : MonoBehaviour
{
    [SerializeField] private ItemConfigDataSo _starterItem;

    private Scope _scope;

    private void Awake()
    {
        _scope = new Scope("game");
        _scope.Register<IInventory, InventoryService>();
        _scope.RegisterInstance(_starterItem);
        _scope.Build();
    }

    private void OnDestroy()
    {
        _scope.Dispose();
    }
}
```

`Build()` 之后：按注册顺序创建全部注册项 → 对实现 `IInjectable` 的实例调用 `Inject` → 对实现 `IInitializable` 的实例调用 `Initialize`。

## 五、子 Scope

```csharp
var levelScope = _scope.CreateChild("level");
levelScope.Register<ILevelRule, LevelRuleService>();
levelScope.Build();

var rule = levelScope.Resolve<ILevelRule>();
levelScope.Dispose();
```

- 子 Scope 未注册的类型会向父 Scope 递归查找。
- 子 Scope 的同类型注册遮蔽父 Scope 的注册。
- **子 Scope 需自行释放，父不代管。**

## 六、驱动表现

```csharp
var config = _scope.Resolve<ItemConfigDataSo>();
var data = new ItemData(config);

var controller = host.AddComponent<ItemController>();
var worldObject = host.AddComponent<ItemWorldObject>();

controller.Initialize(data);
worldObject.Initialize(controller);

_scope.InjectHierarchy(host);
```

之后：

- **状态**：`WorldObject` 读 `Data`（经 `Controller` 路由），刷新表现。
- **命令**：`WorldObject` 调 `Controller` 的意图方法，`Controller` 走完流程后发 C# `event`，`WorldObject` 订阅。

## 七、用 `TryResolve` 做可选依赖

```csharp
if (_scope.TryResolve<IAnalytics>(out var analytics))
{
    analytics.Track("boot");
}
```

未注册返回 `false` 且不抛异常；解析过程中出现的其它错误（循环依赖等）仍会抛出。

## 八、异常类型

| 异常 | 触发场景 |
| --- | --- |
| `ScopeResolveException` | 类型未注册，或实现类型没有 public 构造函数 |
| `ScopeCircularDependencyException` | 解析栈上出现重复类型 |
| `ScopeStateException` | `Build` 后注册、重复 `Build`、未 `Build` 就解析、`Dispose` 后使用 |
| `ScopeException` | 上述三者的基类 |
